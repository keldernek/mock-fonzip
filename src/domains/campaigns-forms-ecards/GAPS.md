# campaigns-forms-ecards gaps

Spec gaps found while implementing the campaigns-forms-ecards operations. Use the tables in `../../../PARITY.md` as the format: the spec location, the problem, and what the mock does. Give each waiver in `parity-waivers.json` next to this file a matching row here.

## Waived

| Spec location                                                                                                                                                                                                           | Problem                                                                                                                                                                                            | Mock behavior                                                                                                                                                                                  |

| 404 on `GET /fundraising-events`, `GET /fundraising-teams`, `GET /forms`, `GET /form-answers`, `GET /ecard-categories`, `POST /ecard-categories`                                                                        | The request names no object.                                                                                                                                                                       | 404 never occurs. Waived.                                                                                                                                                                      |
