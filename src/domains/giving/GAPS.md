# giving gaps

Spec gaps found while implementing the giving operations. Use the tables in `../../../PARITY.md` as the format: the spec location, the problem, and what the mock does. Give each waiver in `parity-waivers.json` next to this file a matching row here.

## Simulations

`POST /__mock/simulations/giving/{name}` runs the public-site events. Each one raises the DONATION webhook.

| Simulation        | Event                                                                                                                                                                                                 | Webhook status |
| ----------------- | ----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | -------------- |
| `public-donation` | A donor pays by card on the public site. Takes `amount`, plus `user_id` or the names of a new donor. Optional: `currency`, category, page, campaign, form, marketing channel, and a campaign message. | 3              |
| `failed-donation` | The same payment is declined, with `error_code` from the seeded payment errors (default `51`).                                                                                                        | 5              |
| `refund-donation` | An admin refunds a successful donation (`donation_id`, `reason`, `refunded_by_id`). Refunding a donation that is not successful gets 409.                                                             | 4              |
